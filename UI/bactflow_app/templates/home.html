How BactFlow runs

Work left to right: QC the reads, assemble, then interpret the genomes. Only one pipeline can run at a time. Memory is a hard cap — keep it below what the machine actually has.

Start

Home

Launch QC, Assembly, or Post-assembly from the cards or the top bar. Switching modules does not reload a run that is already open. While a process is live, Start / Filter / Install on the other modules stay inactive.

Resources

CPUs and Memory

  • CPUs — threads for Nextflow, seqkit, Flye, SPAdes, Bakta, and similar tools. The CPU gauge is relative to this value.
  • Memory (GB) — hard cap for the run. The memory gauge uses this as the denominator (used / cap), not the whole machine. Nextflow cannot schedule more than this; SPAdes is passed -m. Values above host RAM minus 1 GB are reduced automatically.
  • Small laptops: 4–8 GB. Assembly, CheckM, and GTDB-Tk are the hungry steps.
QC

Launch QC

Point at a FASTQ folder, choose the output directory, then:

  • Read type — Illumina, ONT, or PacBio.
  • Concat reads — pool barcode folders into one FASTQ per sample.
  • Filter reads — length/quality gates.
  • Display read statistics / Visualize reads — seqkit stats and quality plots.
QC outputs

How to read QC results

  • FASTQ list — files that will go to assembly. Tiny leftover files after pooling are often failed barcodes; trim them if they are junk.
  • SeqKit table — num_seqs is read count; avg_len / N50 should match the chemistry (Illumina ~150–300 bp, ONT often kb-scale, HiFi ~10–20 kb). Very low avg_qual means skip or re-basecall before assembling.
  • Quality plots — a pile of short, low-Q reads is contamination or a failed library. PacBio CLR looks noisier than HiFi; that is expected.
Assembly

Launch Assembly

  • Assembler — Flye (ONT), SPAdes (Illumina isolate), Unicycler (hybrid), PacBio Flye.
  • Resume — continue a previous Nextflow run in the same output directory.
  • Clean up work dir — after success, delete .nextflow-work and temp files under the output directory. Leave False if you will Resume.
  • Start BactFlow. Stop cancels the tree. Display results appears when reports exist.
Assembly outputs

How to read assembly results

  • FASTA genomes — under the output asm_out_dir/fastas (and circulated copies if you enabled that). One file per sample.
  • QUAST — N50 and contig count: isolate bacteria often land near 1–10 contigs with N50 in the Mb range. Hundreds of tiny contigs usually means leftover reads, the wrong assembler, or a mixed sample. Largest contig near the expected genome size is a good sign.
  • GC / genome size — should match the species you think you sequenced. A 2 Mb assembly for a 5 Mb organism is incomplete.
  • Terminal — Nextflow process names turning green means that step finished. Red / exit code ≠ 0 is the step to re-run after fixing paths or Memory.
Post-assembly

Launch Post-assembly

  • Genome directory — folder of FASTA files. Required unless you only install.
  • QUAST — assembly metrics. On by default.
  • CheckM — completeness/contamination. Needs a database. Heavy RAM.
  • GTDB-Tk — taxonomy. Needs the GTDB data path. Very heavy.
  • Bakta — annotation. Linear plots, AMR, orphans, and the heatmap read these results.
  • geNomad — plasmids / viruses with a local database.
  • MLST — PubMLST sequence typing. No extra database path.
  • Clean up work dir — after success, delete .nextflow-work and temp files. Leave False if you will Resume.
  • Generate report — HTML + PDF summary of every result table with written interpretation.
Post outputs

How to read post-assembly results

  • CheckM — completeness above ~90% and contamination below ~5% is a typical isolate. High contamination suggests mixed cultures or assembly artifacts.
  • GTDB-Tk — reports the closest GTDB species/genus. Classification confidence drops when the genome is incomplete or novel.
  • MLST — scheme + sequence type (ST) per genome. Allele heatmap shows which loci differ. Untyped means no PubMLST scheme matched.
  • Bakta table — CDS, rRNA, tRNA counts. Missing rRNAs often mean a fragmented assembly, not a mysterious organism.
  • Linear plot — arrows are genes. Highlight AMR shows antibiotic (not metal/stress) genes. Cordify draws homologs between stacked genomes; Find orphans blinks CDS with no match to the partner.
  • Heatmap — gene abundance or prevalence across annotated genomes. Tight clusters are similar accessory content; singleton rows are sample-specific genes.
  • geNomad — plasmid and virus tables. Short circular contigs with plasmid hits are the ones to inspect first.
  • Genome report — Generate report writes narrative text plus tables to bactflow_report/ (PDF and HTML). It only uses results already on disk.
  • VCF / SV tables — SNPs and structural variants versus the wild-type FASTA you picked. Dense SNP piles in one region can be a mapping artifact or a real hotspot.
Lock

One process at a time

Navigation is always allowed and does not restart a module. Launch buttons on other modules stay inactive until the current job exits or you press Stop.
