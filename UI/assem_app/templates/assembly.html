Assembly Parameters
On for ONT barcode folders and PacBio per-sample movie folders (TL110_fastq/*.subreads.fastq). One pooled FASTQ is assembled per sample.
PacBio subread chunks are usually .subreads.fastq. Leave blank to auto-detect.
SPAdes uses Illumina paired-end files in the FASTQ directory (sample_R1.fastq.gz / sample_R2.fastq.gz). Assemblies are written to asm_out_dir/fastas/<sample>_spades.fasta and will not replace existing ONT or PacBio FASTAs in the same folder.
Point the FASTQ directory at the parent folder of sample subdirectories (e.g. …/pacbio/ containing TL110_fastq/, TL19_fastq/), or at one sample folder of *.subreads.fastq movie chunks. Concat Reads should stay True so each sample is pooled before Flye. Assemblies write to asm_out_dir/fastas/<sample>_pacbio.fasta. Reads are classified first (HiFi/CCS vs subreads/CLR). If they are subreads/CLR, set PacBio read type to pacbio-raw (not pacbio-hifi).
Required for Unicycler. Long-read samples are paired to Illumina by sample ID, so TL110_Native_R1041.fastq matches TL110_Illumina_R1.fastq.gz / TL110_Illumina_R2.fastq.gz (or TL110_R1/TL110_R2). Hybrid assemblies are written to asm_out_dir/fastas/<sample>_unicycler.fasta.
Runs before coverage filter when both are enabled.
