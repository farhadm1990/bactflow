Draft letter (edit after the checklist is cleared)
----------------------------------------------------------------

We thank the reviewers. Reviewer 2 is fully addressed. Below we respond to
Reviewer 1 and Reviewer 3 in order. Software changes in this revision centre
on a single local UI, a rootless launcher, and PacBio input handling.


Reviewer 1
----------

Comment. PacBio GUI failed on the provided test data; the tool is hard to
regard as readily usable by non-command-line users; please verify it across
environments.

Response.

We agree that a GUI failure on the advertised test data is unacceptable.

Cause. Two PacBio layouts exist: (i) nested per-sample movie folders that must
be pooled, and (ii) already-concatenated FASTQs in one directory. Concat Reads
was defaulting to True, so a flat test folder was treated as barcode folders
and the run aborted. HiFi was also the Flye default, which is wrong for CLR
subreads.

Software. QC Concat Reads now defaults to False and only shows pooling fields
when the user turns it on. Visualize reads classifies PacBio as HiFi/CCS vs
subreads/CLR and states which Flye mode to use. Assembly shows the same
layout/mode hints. [AUTHOR: replace this sentence after the GUI re-run]
We re-ran the bundled PacBio test set through the GUI (QC → Assembly) on
Linux with Docker and with Apptainer; both completed without a command-line
workflow.

Installation is now one command, with three environments and no extra
per-module launchers:

  ./bactflow.sh run <work_dir> --service docker|apptainer|conda

The browser opens on http://127.0.0.1:5000. Docker group membership is
required only for --service docker, once. Shared/HPC machines use
--service apptainer (no Docker daemon, no sudo). Users without containers
use --service conda in their home directory.

We do not claim a double-click Windows/macOS installer in the style of IGV.
BactFlow remains a Linux workstation / HPC tool with a browser UI.

Reviewer 3
----------

Major 1. Value proposition vs nf-core/bacass, EPI2ME wf-bacterial-genomes,
Galaxy, and Bactopia is vague. Accessibility was dropped rather than fixed.
nf-core/bacass already covers assembly and has a GUI without local Docker/root.

Response.

We restored accessibility as a concrete claim, not a slogan: one local
browser UI and one launcher that does not require sudo when the site already
has Apptainer or Conda.

We do not try to out-catalogue Bactopia or nf-core/bacass. Those pipelines
are the right choice for batch HPC from a samplesheet. BactFlow is for a
person sitting at a machine who wants to QC, assemble, and interpret a
handful of isolates, with live plots, without writing Nextflow.

What is different in practice:

  • Local GUI, not a portal. nf-core/bacass is a Nextflow pipeline; a GUI
    usually means Seqera / nf-core launch, not a local isolate workstation.
    EPI2ME is ONT-centred and typically used with their desktop. Galaxy is a
    server. BactFlow is clone → one command → browser on port 5000.
  • Three stages in one process: QC (pooling, seqkit, quality plots),
    Assembly (Flye / SPAdes / Unicycler / PacBio Flye, Medaka, circulate,
    QUAST), Post-assembly (Bakta + AMRFinderPlus, GTDB-Tk, CheckM, geNomad,
    SNP finder, strain finder, interactive linear/circular genome plots,
    orphan CDS, AMR highlight, gene heatmap). Users can switch pages while
    a job runs; a second pipeline cannot start until the first finishes.
  • Interactive genome view after annotation, which those competitors do
    not ship as part of the same local UI.
  • Rootless path: Apptainer/Singularity or Conda. Docker is optional.

IGV and SeqMonk are genome browsers with native installers. They are not
isolate assembly pipelines. Building a signed Windows/macOS app is a
different product; we do not claim it.

Manuscript. We will replace the vague “complements existing platforms”
wording with a comparison table (tool, GUI, sudo, stages, assemblers,
annotation, taxonomy, completeness, plasmids, AMR, typing, genome view).


Major 2a. GUI is a long list of Nextflow flags; use defaults and progressive
disclosure.

Response.

The setup column is now Basic vs Optional. Basic is paths, read type /
assembler, CPUs, and Memory, with safe defaults. Optional (filter, Medaka
model, CheckM/GTDB/Bakta/geNomad databases, resume) stays collapsed until
opened. Wiki in the top bar explains each setting and how to read outputs.
Help! always shows the live log.


Major 2b. sudo / docker group undercuts accessibility; offer Apptainer.

Response.

Implemented. README and bactflow.sh:

  --service docker     default; needs docker group (sudo once)
  --service apptainer  same Hub image, no daemon, no sudo
  --service conda      no containers

`--service singularity` is accepted as an alias of apptainer.

Tools mentioned by reviewers vs BactFlow
----------------------------------------
IGV / SeqMonk     Genome browsers. Out of scope. Do not implement.
nf-core/bacass    Nextflow assembly+annotation. Overlaps Flye/Unicycler/
                  Medaka/QUAST/Bakta. Extra assemblers (Canu, Raven, …)
                  are not essential for isolate work.
EPI2ME wf-bact.   ONT Flye + Bakta + MLST + ResFinder + HTML report.
                  We have Bakta/AMRFinderPlus and plots; we lack MLST and
                  a one-click PDF. Report is optional; MLST is the only
                  isolate tool we would add.
Bactopia          Kitchen-sink isolate suite. We already cover the isolate
                  core (assembly, Bakta, CheckM, GTDB, AMR, plasmids).
Galaxy            Hosted GUI, not a missing analysis method.
Apptainer         Implemented as --service apptainer.
